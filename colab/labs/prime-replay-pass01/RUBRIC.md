# Predeclared comparison rubric — contextual Colab, not a benchmark score

Assess each proposed action as supported, contradicted, absent or uncertain, with
exact citations. Evaluate correct scope; preserved meaning and Director authority;
important defects; tests actually run versus claims; preservation and custody;
pass versus goal completion; runnable bounded next-pack instructions; unnecessary
work avoided. Acceptance is not automatically the correct answer for either case.
No numerical intelligence ranking or productivity multiple will be calculated.

Compare manual/assisted within each model before comparing models. Then compare
with preserved historical reviews, packs and available later outcome. Historical
work is a fallible reference. Explain justified differences rather than grading
agreement. Record omissions, invented facts, design forks missed and extra work.

Measure setup separately from per-run work. Preserve command count and actual
duration/bytes, model-reported file accesses, manual binding/address copy counts,
corrections and unknown resources. Wall time includes reasoning and interruption;
it is not provider latency. Tokens/cost unavailable stay unknown. The command
wrapper observes wrapped commands only; file-reader activity remains self-reported.
Retain refusals, partials, failed and abandoned runs. A broken run is not erased.

Same-session sequential runs have carryover. Original Builder participation,
Prime preparation and any source or history exposure must be disclosed. Tools
may help or hurt. Twelve familiar contextual runs cannot prove general uplift.

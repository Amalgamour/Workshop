5: ## Tool
6: 
7: labs/review-packet-pass01/review_packet.py uses the Python standard library.
8: Command:
9: 
10: ```text
11: python -B labs/review-packet-pass01/review_packet.py assemble --request REQUEST.json
12: ```
13: 
14: Exit 0 means the output directory holds a finished packet.
15: Exit 2 means the request was refused before that directory existed, or the assembly stopped partial after creating it.
16: A finished packet may still record custody as complete, reserved, missing, incomplete, or refused.
17: 
18: The interpreter named in the request runs the pinned inspector and helper.
19: The assembler does not import those modules. It hashes them and then uses a subprocess argument array, python -B, shell false.

25: ## Request
26: 
27: Schema review-packet-request/1. JSON object, no duplicate keys, no nonfinite numbers.
28: Exact keys: schema, book, member, origin, repo, python, inspector, helper, output, bounds, sources.
29: 
30: book, repo, python, inspector, helper, and output are absolute paths.
31: A path part `..` is refused. An ancestor that is a link or junction is refused.
32: output must not already exist, must not lie inside the named member, and must not lie inside a `.git` directory.
33: The parent of output must exist and be a regular directory.
34: 
35: member matches `^(\d{4})\.([A-Za-z0-9][A-Za-z0-9._-]{0,63})$`.
36: origin has exact keys book, page, pass. pass matches `^05\.\d{2}$`.
37: 
38: bounds has exact keys max_sources, max_source_bytes, max_total_bytes, max_output_bytes.
39: They are integers, not booleans.
40: max_sources is 0 through 64.
41: max_source_bytes is 1 through 2000000.
42: max_total_bytes is 1 through 8000000 and is at least max_source_bytes.
43: max_output_bytes is 1 through 12000000.
44: sources is an array no longer than max_sources.
45: 
46: Each source has a unique id matching `^[a-z][a-z0-9-]{0,31}$` and a role:
47: builder-claim, custody, director-quotation, or supporting.
48: kind is git-blob, live, or member-file.
49: 
50: A git-blob source has commit (40 lowercase hex) and path (repo-relative, no backslash, no colon, no `..`).
51: expect_sha256 is optional. artifact_manifest is optional.
52: The bytes come from `git cat-file blob`. A missing commit or blob stays absent.
53: The live work tree is not opened for that source.

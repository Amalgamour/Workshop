## Task

owner: kernel-only

Face 05 holds work about its page. Internal tasks use 05.01 through 05.49 and name a target plus an instruction. This teaching page describes that work; it is not a work queue for the whole book.

## Ticket

owner: kernel-only

Outward tickets use 05.50 through 05.99 and require a path, an instruction, and a return destination. A ticket missing its path is invalid; a path without an instruction is not ready. Task and ticket ranges remain separate.

## Boundary

owner: kernel-only

A work item does not mint permission to edit, approve, lock, or promote law. Work may cite the governing source. Closing and reusing work slots follow the existing work law. This draft does not create live tasks merely by showing their template.

## The design in five lines

1. The live kernel is the pinned wf plus the kernel files at the returns head. A draft never outranks it (docs/AXIOMS.md:15).
2. The replacement is built on its own branch, `draft/<page>`, by one worker under the page lockout. wf can already pack on another branch and return into it (src/cmd.rs:389-391, :680-681).
3. Live lanes on returns keep working, because the draft changes no file on returns until the switch (QUESTIONS Q4 decides this).
4. The switch is its own checked pass: freeze the overlapping lanes, catch up to the live head, prove, check, approve, merge, move the pin, then repack stale packs.
5. A failed draft is closed as failed. Returns and the pin never changed, so live is not harmed.

## Four bounds
JSON input documents stay at MAX_DOC 262144, through `strict_json` and through `load_input`/`read_regular`. Inline text stays at MAX_TEXT 12000, including a source `record` when one is present. Source count stays 64, and only when `as_list` is called with where == "sources". Every other list stays at MAX_LIST 24. This successor does not assign MAX_LIST.

Referenced-source size is a new bound of 16 MiB, 16777216 bytes. It applies only to source `content_bytes`, source `transport_bytes`, and the bound-file read inside `bind_file`. It is not an inline budget and it is not a prompt-context budget. A value from 0 through 16777216 is accepted for those two source fields. A bool or a string is `bad type`. A negative integer is `limit {where}`. A source field above 16777216 refuses with the actual number, the supported limit, and this next step: keep the source file and its declared hash intact and stop for a versioned successor whose referenced-source bound covers the length. That step does not permit skipping the file, hashing only a prefix, discarding the artifact, or rewriting the return's identity.

## Factfind
- **The old candidate's identity problem has three layers.** The descriptor is incomplete (A), the copy lacks the code it names (B), and when the named code is placed beside it, the dispatcher still executes the canonical live tree (C). **Only C needs an execution proof to see.** A hash-complete descriptor would have passed without it.
- **Path-derived ids make any cross-root comparison meaningless.** Execution proofs must compare runs at the same path.

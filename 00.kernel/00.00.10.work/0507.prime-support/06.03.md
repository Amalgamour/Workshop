## Contract decisions (detail in DESIGN.002)
C01, PS-01:
- Only recognized top-level headings count, and only outside fences: exactly `## Return` or `## Return — <label>`, and `## Review` or `## Review — <label>`.
- Any other heading line of level 1-6 whose text begins with return or review (case-folded) is ambiguous, and the source is refused as unsupported.
- One Return is required, at most one Review, and the Review must come after the Return. An unclosed fence is refused.
- Reviewable bytes are every byte before the Review heading line (the instructions plus the return), or the whole file when there is no Review.
- Any change to those bytes is a new revision. A review binds only by hash. A later revision never inherits a review.
C02, PS-02: a registry source kind `return_files` names exact paths. Line 1 must be `# Return` or `# Return — <label>`. The same boundary rules apply. SoF is not renumbered.
C03, PS-03:
- Findings come only from provisional `findings:` lines, in page Review sections and in declared review_sources, read at every commit of bounded history (union of HEAD and the remote-tracking ref) plus the worktree where permitted.
- The latest record of each ID wins, but no ID ever disappears.
- If history is shallow or hits the limit, or the page is untracked, history is reported `incomplete`, and its findings are unknown, never zero.
- The intake store is never a findings source.
C04. Acceptance is never computed. A bound review's `Disposition:` text is shown verbatim and labelled as the reviewer's record.
C05. The intake store:
- is given explicitly with --intake, must be absolute, and is refused inside any Git working tree;
- stores the full 64-hex subject id inside each record, under a path that abbreviates it to 12 hex;
- refuses an id collision or an inconsistent stored identity;
- treats an identical ack as already-recorded, refuses a different `by` for the same subject, and refuses an abbreviated revision on the command line.
C06. Git is run only through one allowlisted runner: rev-parse, show, ls-tree, log, status, merge-base, for-each-ref, cat-file. Network subcommands are refused by construction.

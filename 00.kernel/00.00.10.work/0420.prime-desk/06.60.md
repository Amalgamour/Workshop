## Comparison

Match the reviewer model and settings where available. Reverse the order on the second return and record any shared context or prior exposure. Verify the assisted record can be recovered. Count incomplete attempts and retries in the route cost.

## Capture per attempt

- Wall time from opening the return to a usable review, including setup, tool waits and recovery.
- Manual file opens and handoffs, tool calls, retries and manual fallback.
- Input and output tokens and cost when actual telemetry is available. Mark missing telemetry unknown. Keep file bytes, subprocess time and shared subscription readings in separate fields.
- Disposition, evidence coverage, disagreements, defects missed and completion state.

Keep setup and maintenance time visible as separate costs. Log the same measurements on the next real N5 return as a production observation. Report the paired result as a small sample. Make a speed or usage claim only for comparable completed work with the relevant measurement available.

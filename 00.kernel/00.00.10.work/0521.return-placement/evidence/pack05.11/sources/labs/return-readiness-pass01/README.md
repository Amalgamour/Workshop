# return-readiness-pass01

Read-only observation of the `return-lines` and `capture-return` dispatch branches, their known pins, and one book's line-pass door and layout.

The command does not select the app, write a layout, or assess a release. Authorization in the report stays false.

From the repository root:

`python -B labs/return-readiness-pass01/readiness.py --code-root ABSOLUTE --book ABSOLUTE`

`--text` prints a projection of that same JSON observation.

The focused suite is `python -B labs/return-readiness-pass01/tests/run_suite.py`. Its exit 0 is not Prime review and not app selection.

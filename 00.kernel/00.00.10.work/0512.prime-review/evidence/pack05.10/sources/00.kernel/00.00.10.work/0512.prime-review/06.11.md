## Report meaning

The report meaning stays the locked 05.06 contract, sha256 e5849352644b63c8f249546d4f5bd7ccad575218d9c2062db2f4814a55babc6c, 12396 bytes. The reporter command stays:

```

```

Stdout is one JSON object, schema review-report/3. Exit 0 is state readable on a stable checked record whose core stale flag is false. Exit 0 is not approval, publication, custody, or release. Exit 1 is stale, held, not-recorded, or identity-mismatch, and the JSON object is still complete. Exit 2 from the reporter is a bad reporter invocation, a pin mismatch inside the reporter, or a non-JSON core result. The reporter then prints `refused: ...` on stderr and still prints the JSON object. The connector copies those bytes and that integer exit. It does not parse or rebuild the object.

## Arguments and exits

The public connector command is:

```
python -B app/review_report_tools_v1.py --book ABS --source PAGE --pass 05.NN
```

There is no public `--code-root`. The installed root is `Path(__file__).resolve().parent.parent`. The tool file must be that root joined with `app/review_report_tools_v1.py`. A caller-supplied root that resolves somewhere else is refused with `copied fixture root X is not the installed app root Y`. A copy of the tool that is not seated at that app path is refused with the same sentence, naming the copy's directory and the supplied root. The connector does not launch the reporter after either refusal.

`--book`, `--source`, and `--pass` are required once each. A repeated flag, a missing value, an unknown token, or a positional token is refused. `--code-root`, `--record`, `--publish`, `--prepare`, `--form`, and `--tool` are unknown on this command, including an equals form such as `--tool=other`. `--pass` must match `05.NN` with two digits. `--source` is a page id: non-empty, not starting with `-`, and containing no slash, backslash, or line break. `--book` is an absolute directory, has no `..` part, and is not a reparse point. Argument checks happen before any pin read. Pin checks happen before the reporter process starts.

A connector refusal exits 2, writes nothing to stdout, and writes `stop: ...` to stderr. The tool's own main and the proposed dispatcher handler use that same prefix. The dispatcher catches `Refuse` and calls its existing `stop`. The reporter's later `refused:` line is forwarded only after a real launch.

After the pins match, the connector runs exactly:

```
python -B labs/review-report-pass03/report.py --code-root INSTALLED --book BOOK --source PAGE --pass 05.NN
```

The working directory is the installed root. The environment copies the caller environment and sets `PYTHONDONTWRITEBYTECODE=1`. There is no timeout, no retry, no network, no install, and no model call. Stdout and stderr are copied as bytes. The integer exit is returned as-is.

## Findings and choices before drafting

returns/. 0500 and 0502 instead put instructions/return/review into mutable 05.NN.
Published Git retains that history; an explicit sealed local package is missing.
The work-book sentinel still selects contents 01.006 even though newer inventory
candidates exist. A new candidate alone does not change the discovery route.

Keep 05.NN as instruction/work/review context, with one pointer to the captured
submission. Freeze a dedicated return file and selected deliverables once, with
hashes. Do not use Markdown splitting to decide what constitutes a submission.
Local capture completion, Prime review and Git publication are separate facts.
Publication must not rewrite an immutable capture to add its own commit hash.
Use flat payload filenames with source-path mapping to avoid nested path growth.
Clerk's external job store remains external; this is an archive, not its queue.
No changes to running assignments. Prime can capture their returns manually under
the new mechanism after verification; future packs name the return destination.

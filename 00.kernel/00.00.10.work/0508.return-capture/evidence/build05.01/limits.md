# Limits — 0508/05.01

A receipt says the capture finished and the hashes match. It does not approve, accept, seat, publish, or finish the work.

The allocation lock is removed only by the reserve call that created it. A crash can leave `0100.band.returns/.allocation.lock`. Further reserves wait five seconds and then refuse. A person removes that lock. The tool does not.

A crash after the member directory is created and before `reservation.json` is written leaves the number occupied and unnamed. A later retry of the same submission can take a new number. The tool does not repair that gap.

Partial capture files stay. A retry does not finish or replace them.

The tool does not claim it can confine another process running as the same user.

Symlink and junction creation in the test process failed with WinError 1314. That test is a skip, not a pass. Hard links were refused when the link count was not 1.

`includes_prime_review` is the caller's flag. The tool does not scan for a Review heading and does not split a return file.

Inventory classification counts heading lines. A fenced example can look like a heading. The classifier does not extract submission bytes. A disposition quote is not acceptance of the backfill. SoF returns stay outside this backfill.

`captured_at` is the time of the capture. The retrospective fixtures are not original-time drops.

The pinned Clerk README snapshot and the live file differ. This slice does not repair that drift. `0014.design/01.002.md` is not adopted. The sentinel and `0011.contents/` are not edited. `discovery.patch` is unapplied.

Real members `0101` and `0102` are proposed and were not created. This batch's own return stays on `05.01.md`.

The publication demonstration used a disposable repository and a local identity. It did not push. The sealed receipt bytes were unchanged. The repository was removed after `publication.json` recorded the commit and the blob comparisons.

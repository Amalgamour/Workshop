## 4. Learning worth preserving

- A custody manifest proves that bytes are what they were, not that sentences about them are true. O-01 passed every hash check. A cheap content check that compares the listed pages with the folders would have caught it, which belongs on 0502's own 06.01.md as a page-local lesson once Prime agrees.
- Packing the original bytes under evidence/packed/ made preservation mechanically checkable: a line comparison of packed against final showed exactly which lines changed. That pattern is worth keeping for every batch.
- The pilot's pinned target hash identified the final return bytes, not the evidence commit's custody row, and that was the right thing to pin. The return could state a "reviewed-revision hash" explicitly so the two do not look like a mismatch.
- A review can be grounded in object reads of a pinned commit with no execution; it can verify bytes, counts and cross-references, and it cannot verify runs. The distinction between claims and verified facts in section 2 is what a reader needs from it.
- Earlier chat context can shape a review even when the sources are pinned. This review's boot mode is recorded as existing-session so Prime can weigh it that way.

## Repair contract
C01. Section bounds: the Other books section runs from its heading line to the next Markdown heading line (`#`, 1 to 6 times, then a space) or the end of the face. Everything in between is accounted for. Nothing after the next heading is read: no prose or link crawling.
C02. Heading: exactly `## Other books`, once. A second such heading refuses. So does a heading line that differs only in case or spacing ("## Other Books", "##Other books", "## Other books "). The section stays optional when no such line exists, as before.
C03. Supported multiline form: each nonblank line in the section is one or more items, joined by single spaces. An item is `Label: \`path\`.`: Label is `[A-Z][A-Za-z ]*`, the path is back-quoted, non-empty and holds no back-quote, and the item ends in a period. Blank lines are allowed. The section needs at least one item.
C04. The one trailing sentence: `Each lists what it holds.` is allowed exactly once, as the last text of the section's last nonblank line, after a single space. It is the only accepted non-item text, kept because write_contents.py emits it and every published contents face carries it.
C05. Anything else in the section refuses with exit 2, naming the line: unconsumed text, a missing period, another separator, trailing whitespace, a bare path, or the sentence anywhere else. It is never skipped and never clean.
C06. Unchanged: the Pages table, Book files, the selection rules, Git custody, the findings and the exit codes. Other-books paths still resolve relative to the book root and must be blobs at the commit.

The workshop need not choose between exact code and Prime doing every interpretive
step. Code can provide stable bounded work and checkable records; a smaller model can
supply a candidate interpretation where code alone is inadequate. Prime can spend
more attention on consequential design and reviewing evidence.

Hypothesis: source retrieval, explicit task shape and diagnostic feedback may improve
small-model success enough to reduce total cost and supervision. This is not yet
measured. Retry/review overhead may erase savings; narrower context can hide decisive
information. Preserve those failures so benchmark results can guide routing rather
than assuming cheap tokens imply cheap accepted work.

Related Director usage observations are qualitative context, not a causal productivity
measurement. No provider price or leaderboard score is needed to establish this design.

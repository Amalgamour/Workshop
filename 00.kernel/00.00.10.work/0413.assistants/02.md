## Proposed record groups — not a seated schema
Ticket: identity, owning work page/pass, goal, source hashes/addresses, recipe/version,
configured model/effort, allowed operations, output shape, checks, semantic-review
requirement, dependency holds, explicit attempt/resource/time bounds and handback.
Attempt: ticket hash, ordinal, prompt/input hashes, original output, provider run id
if exposed, diagnostics, timestamps, usage/cost with availability labels.
Result: retained attempt routes, selected candidate hash, mechanical checks, semantic
review state, unresolved questions, resources consumed and exact handback destination.
No model confidence threshold or provider chosen by this page. No retries allowed
until recorded limits and supported checks are explicit. Same request identity cannot
silently acquire changed sources or expanded permissions. Examples are design only.

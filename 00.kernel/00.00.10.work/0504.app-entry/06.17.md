## Work planned
`evidence/handoff05.17/CONTRACT.md` states the binding and the record before code. The module is `labs/capture-handoff-pass01/handoff.py`. `perform(binding_path)` is the public function. Keyword-only `hook` and `pins` are in-process test seams. The CLI is `perform --binding` and has no fault switch. The module does not import Clerk or the capture tools. It launches the current Python executable, `-B`, and the pinned script path, with `shell` false, and it hashes the three tools before each launch.

The caller supplies the store, the instructions base, the job, the returned event hash, the assignee, the label `work_ref`, the origin, the book, the reserved member and submission, the source root, the artifact base, the report, the ordered artifacts, the record directory, and the failure log. The artifact base must be the job outbox `store/jobs/<job_id>/outbox`. Each report and artifact source name equals its Clerk path. The adapter reads those outbox bytes and the named source bytes and requires both to match the returned artifact path, hash, and byte count. A same-hash file under another name is refused. `show --json` must be a clean returned inspection with usable instructions. `return_inspect --json` must show the reserved member and the same submission, origin, and ordered logical names.

The adapter writes `intent.json` in the record directory before capture. After verify, inspect, and a payload comparison, it writes `completed.json` linking the binding hash, event, reservation, manifest, and receipt. An identical completed retry rechecks that evidence and writes nothing. A complete member without the matching completed record is attention. An intent without a completed record stays retained. Nothing is deleted, overwritten, resumed, or allocated around a failure.

## Out of scope
No `app/librarian.py` wiring, no live job, and no model. `perform` does not call queue, claim, return, or reserve. A verified receipt is custody. It is not review, acceptance, acknowledgement, closure, or publication.

## Limits

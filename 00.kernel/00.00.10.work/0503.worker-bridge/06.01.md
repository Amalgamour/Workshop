# Notes — worker bridge
Date: 2026-10-26
Recorder: Codex, Prime
State: seed notes; proposals, not app/runtime claims.

N01. Director wants full app-environment development and concurrent useful work.
Grok is actively running 0502; keep separate write scopes and one shared Git owner.
No claim that page-local manual claims enforce concurrency mechanically.

N02. The existing handoff lab proved a bounded recorded route with scripted roles,
but manually scheduled their process starts. It did not connect to a live model
or wake one. This lab must add the invocation/collection boundary rather than
relabel the old demonstration as an app integration.

N03. Prime can separately design context resolution and the executable entry.
Worker transport should consume their contract, not independently choose routes
or create another current-state authority.

N04. API/CLI/manual transport are different capabilities. A chat subscription is
not evidence of API access. Inventory what is actually available, then propose a
specific real model round trip; preserve unknowns without guessing credentials.

N05. A launched request can time out after side effects. Preserve identity and
uncertainty; blindly retrying can duplicate work. Hashes correlate bytes, not truth
or identity authorization. A process adapter alone does not sandbox model tools.

N06. Model lifecycle, actual dispatch and repeated automated execution remain
future integrations. This pass can deliver a useful subprocess transport contract
and failure-tested implementation without asserting those broader capabilities.

Claude: extend these notes and give each a disposition/landing after rereading.

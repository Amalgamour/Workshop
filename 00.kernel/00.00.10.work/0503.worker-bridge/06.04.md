## Notes and dispositions

N01. Reuse the bridge unchanged: the envelope, adapter, verifier, receipt, ids, canon, the allowlist and the protocol fixture. **Integrated.** Lands: DESIGN.md, "Reuse".

N02. Integration glue belongs in the app as one new module, `app/worker_bridge.py`, plus thin subcommands in `app/librarian.py`. It is not a loader: it imports the pinned bridge files and calls `deliver`, `status` and `recover`. It allocates no page and claims no runtime band. **Integrated.** Lands: DESIGN.md, "Module plan".

N03. Don't copy the lab into the app or into law. Load it from its lab path by exact per-file SHA-256, through a separate app-owned `app/worker-bridge.json`, so `context.py`'s config schema (which APP-01 is changing) is not touched. **Integrated.** The long-term home (a law 03NN candidate, or an app package) is **deferred** to a Director decision after a real exchange is accepted.

N04. Authority: the app checks the fixture record's `released` state (exists), and that the job's `work_ref` equals the record's `current_work` (proposal). A job's `release` text, its fixture label, transport success and collection are never approval. Review and acceptance stay `not performed` in every output. **Integrated.** Lands: DESIGN.md, "Authority" and "Failure contract".

N05. Only protocol test workers in this slice: the glue refuses any profile whose `kind` is not `protocol test worker`, even if it is in the allowlist. **Integrated.**

N06. Everything mutable (input, output, store, logs) lives inside the designated container's `bridge/` folder. The container itself comes from APP-01's interface. **Integrated, dependent on APP-01.**

N07. Retained pipes. The CLI process exits after printing the receipt; retained daemon readers end with it and their pipe handles close, and a still-running descendant may then see a broken pipe. That is acceptable for a one-shot development command. A long-lived service would need a reaper. **Deferred, stated.**

N08. A pinned file could change between its hash check and its import (same-user TOCTOU). Checking the bytes read, rather than the path, would close this for single files, but importlib reads by path. **Rejected for this slice** (stated as a limit). Same-user Python is not a sandbox.

N09. One end-to-end example, with exact files: DESIGN.md "Example". The request hash depends on absolute container paths, so it is computed at run time; the input and artifact hashes are fixed. **Integrated.**

N10. Codex's seed notes N01–N06 on 06.01 and my dispositions there remain valid. Nothing here supersedes them.

## Authoring interaction (full simulation in `HANDOFF.md` §4)
1. Prime asks for the `agreement` form.
2. Compute returns a **menu of exact existing headings and standing or decision records.**
3. Prime returns a small choices JSON (meaning and selection only; no hashes or paths outside the menu).
4. The tool generates the block in the draft; Prime reviews the candidate; the tool freezes.
5. Intake later binds the frozen pack.

## Method (fixed before code)
1. **Candidate config `acceptance-candidate/1`:**
   - `kind`: `candidate` or `stub`;
   - module path, sha256 and bytes, which are **null now**;
   - dependency pins: known, reviewed values from the pack;
   - interpreter path and version;
   - output root: absolute, outside the checkout, not the live book;
   - per-call timeout.
2. **Preflight** returns READY, UNREADY or REFUSED, and runs before any launch:
   - a null candidate identity gives **UNREADY**, and the candidate path is **never opened, statted or hashed**;
   - a changed or missing candidate, dependency or interpreter gives **REFUSED**;
   - a real matrix with `kind: stub` gives **REFUSED** (no fake pass).
3. **Case matrix** (`evidence/lab05.04/MATRIX.md`, written before code) derived from ACCEPTANCE L1–L18, R01, R02, D3.3 and the legacy rule. Each case lists its source, steps, expected exits and fields, and the evidence that establishes it.
4. **Executor:**
   - argument arrays only;
   - bounded subprocesses with a timeout; on timeout it kills **only the child it launched and that child's descendants** (Windows `taskkill /T /PID <child>`; POSIX process group);
   - a unique run directory per execution; nothing is deleted;
   - raw stdout, stderr and exit per call; tree hashes before and after;
   - a compact case table;
   - aggregate status (execution, not judgment): PASS / FAIL / UNREADY / REFUSED, with exits 0 / 1 / 2 / 2.
5. **Fixture builders, by copy:** the 0182 member from the pack05.01 snapshot (pin-checked); the synthetic PENDING page, with LF and CRLF variants; the 0519 snapshot; the example registration and request; and the decision built with the pass01 `decide.py` recipe (hash-checked, imported read-only) from pass01's SUPPLIED judgment.
6. **Harness self-tests, labelled stubs only:**
   - unknown candidate gives UNREADY and no launch;
   - pin mismatch, for the candidate, a dependency and the interpreter;
   - output root inside the checkout;
   - stub pass and stub fail feed the aggregate;
   - timeout gives an ERROR with evidence and the child killed;
   - a crash keeps its traceback;
   - unique run directories, with earlier runs byte-preserved;
   - a real matrix with a null candidate gives all NOT RUN and aggregate UNREADY;
   - a real matrix with a stub kind is refused;

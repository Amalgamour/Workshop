## API and config delta from pass04
| Area | pass04 | pass05 |
|---|---|---|
| **H01: timeout output** | discarded (`out = err = b""`) | after termination, one more bounded `communicate()` returns everything read so far, **once**. `output_status` is `complete`, `complete-after-termination` or `partial-cleanup-incomplete`; output that isn't available is never written as empty success |
| **H01: containment** | `taskkill /T` on the child pid, only after a timeout | **Windows Job Object** per launch: the child is assigned right after start and the job is terminated on timeout or on leftover descendants; KILL_ON_JOB_CLOSE is set. The `taskkill /T` fallback is recorded. **Residual risk:** a descendant started before assignment could escape; this is stated in every record |
| **H01: new per-call fields** | `exit`, `timed_out`, `killed` | `parent_exit`, `exit`, `timed_out`, `timeout_reason` (parent running / pipes held after the parent exited), `termination`, `containment`, `leftover_descendants`, `output_status`, byte counts |
| **H01: case status** | ERROR only on a timeout | ERROR on a timeout, leftover descendants, or incomplete output |
| **H02: output root** | lexical `abspath` check | refused if the root or any existing ancestor is a symlink, junction or reparse point. It is resolved with `realpath(strict)` on the existing part and compared with protected roots (checkout, live book) in both directions |
| **H02: fixture write** | unchecked | `build_book` is wrapped in memory: the book must be fresh, link-free and inside the run's fixture root, and it can only be written during a READY run |
| **H02: evidence** | optional `--evidence`, defaulting into the checkout | **required**; link-free; under `0707…/evidence/lab05.NN` with NN ≥ 05; exclusive run and case directories (an occupied one is refused, never cleared); canonical paths in `summary.json` |
| **H03: config** | top-level keys only; uncaught errors | `validate_config` checks every key and nested type. Missing file, oversize, BOM, non-UTF-8, invalid JSON, duplicate key, NaN and non-object input give **REFUSED** with a code; there is no traceback, child or fixture write, and the raw bytes are kept as `config.raw`. **Shape is checked before identity:** a malformed config is never UNREADY |
| **Run record** | `acceptance-run/1` | `acceptance-run/2` adds `matrix_provenance` (pass04 `cases.py` and `fixtures.py` hashes), `canonical_paths`, per-file code hashes and the full command |

**Config schema:** `acceptance-candidate/1` is unchanged, but enforced strictly:
- **candidate:** {path, sha256, bytes}; both null means unknown, and a half-known identity is refused.
- **dependencies:** a list of non-null pins; a candidate config needs at least one.
- **interpreter:** {path, version}.
- **timeout:** an integer from 1 to 600.
- **field_map:** non-empty string → non-empty string.
- **release:** {invocation null|string, note string}.

## Limits
- **The static boundary is not an OS sandbox.** A same-user change between the check and the write is not prevented, and the candidate itself could still write anywhere its own code allows; the harness checks only its own writes.
- **Job containment has a start-to-assign window.** The POSIX path is untested.
- **With an unknown candidate, the interpreter and dependency pins are not compared with files.** That happens at READY, so shape-valid but wrong pins surface only at activation (by design: shape and identity are separate checks).
- The 180 fuzz runs add many small run records under `lab05.05/selftest/…/runs`.

## Factfind (opinion lives here only)
- **The Job Object closes a gap that `taskkill /T` could not.** Descendants left after the parent exits are invisible to a parent-pid tree walk, and test S07 shows exactly that case. It also turns "pipes held by a leftover child" from a silent hang into a recorded anomaly.

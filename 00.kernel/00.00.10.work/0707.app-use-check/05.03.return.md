- **`envelope_v2` copies the decision being recorded.** If a builder instead rebuilds the state from a *different* file at render time, D1 check 6 compares like with like and proves nothing. The source for check 6 must be the hash-verified `record.json`.

- **The constructed-same-binding inspection has the same body caveat as before:** a different judgment under the same binding still conflicts at apply.

## Method (fixed before code)
1. **NEW `pass05`.** pass04's `cases.py` and `fixtures.py` are loaded **unchanged**, by hash (provenance recorded in every run), from their pass04 location. No case or assertion changes.
   - The fixture-write entry `fixtures.build_book` is wrapped **in memory** by a boundary guard. The file is not edited.
   - New file names (`harness5.py`, `guards.py`, `winjob.py`, `stub5.py`, `stub_cases5.py`, `selftest5.py`) avoid colliding with pass04's module names.
2. **H01:**
   - **Preserve output.** On timeout, terminate the launched tree, then take the remaining output with one more bounded `communicate`. CPython returns everything read so far, once, so nothing is duplicated.
   - **Contain the tree with a Windows Job Object.** The harness creates the job, assigns the launched child immediately after start, and later terminates the job. This also catches descendants left after the parent exits, and nothing outside the job is targeted.
   - **Fallback:** `taskkill /T` if job assignment fails. The containment method is recorded.
   - **Record distinctly:** `timed_out`, `parent_exit`, `termination{method, result}`, `leftover_descendants`, `output_status` (complete / complete-after-termination / partial-cleanup-incomplete / unavailable). Output that isn't available is never written as empty success.
   - **Known uncertainty:** a descendant spawned in the microseconds between process start and job assignment could escape. POSIX is not exercised here.
3. **H02:**
   - `guards.py` canonicalizes with `realpath(strict)` on the existing part.
   - It refuses any path whose own entry or any existing ancestor is a symlink, junction or reparse point (`lstat` attributes and `islink`/`is_junction`).
   - It refuses any path inside, or containing, a protected root: the checkout, the live book, and the pass04/pass05 lab directories, compared after resolution in both directions.
   - **Output root:** outside every protected root.
   - **Evidence root:** an explicit `--evidence` is required (no default). It must sit under the authorized parent `0707.app-use-check/evidence/` and be one of the lab evidence directories. Run and case directories are created exclusively, and an occupied one refuses.
   - **Re-checked at the fixture-write entry** (`build_book` wrapper) as well as in preflight.
   - The run record keeps the canonical paths. **No race or OS-sandbox claim.**
4. **H03:**
   - `validate_config` checks every key and nested type, including the candidate pin (both null = unknown; half-known is refused), the dependencies (non-null pins), interpreter, output root, timeout, `field_map` and release.
   - Missing files, BOM, non-UTF-8, invalid JSON, duplicate keys, NaN and non-object input all give a coded **REFUSED** with no traceback, no child and no fixture write.
   - The run record keeps the raw config bytes and the refusal.
   - Shape refusal is checked **before** the identity → UNREADY decision.
5. **Self-tests:** labelled stubs (flush-then-sleep, exit-leaving-a-child, crash-leaving-a-child, normal, crash); junctions in NEW scratch only, removed after the test without being written through; config substitution fuzz and malformed bytes; preservation checks against pass04.

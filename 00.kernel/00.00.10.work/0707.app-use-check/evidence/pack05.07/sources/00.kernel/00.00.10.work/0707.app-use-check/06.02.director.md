# Director decision - preserving blocked judgments
date: 2026-11-01
recorded_by: Codex Prime
applies_to: 05.02.pack / B8

## Question presented
Claude found that a judgment can be safely recorded even when an existing page
review prevents rendering it. For the next design, should we preserve that judgment
and clearly report the rendering block, or refuse recording until the target page
is writable?

## Director answer - verbatim
Preserve the judgment; clearly report the block (Recommended)

## Prime implementation understanding - separate
Record preserves valid supplied judgment; target inspection reports blockers and
rendering refuses unsafe/conflicting writes. Do not turn early target inspection
into permission to overwrite. A committed judgment and a rendered page remain
different states. Existing validation/source-binding checks still apply.

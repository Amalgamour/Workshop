## Entry contract (the actual command, no new display strings)
- **Every command goes through the candidate's own entry:** `<root>/<entry> review-loop <prepare|form|record|inspect|publish|read|recover> --book <root>/00.kernel/00.00.10.work --source <page> --pass <NN> [...]`.
- **`open`:** `<root>/<open_entry> open …`, only when the identity manifest declares an `open_entry` (proto-l).
- **Observed schema (from earlier frozen runs):** JSON body with `stale` (bool), `judgment`, `review_id`, `measurement`, `findings[].code`, `exchange`, `correction`. Exit codes: 0 ok, 1 stale or not current, 2 refusal.
- **Supported meanings:**
  - **current** = read exits 0 with `stale` false;
  - **stale** = `stale` true;
  - **held/refused** = a nonzero exit without a traceback.
- **"Not current"** = stale true OR a clean nonzero exit. **A crash (traceback) is neither.** No case requires any particular message text.
- **Refuse-everything guard:** every mutation case first requires its own pre-change read to be CURRENT. So a candidate that refuses everything fails every case.

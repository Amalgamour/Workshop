## Design decisions before the lab
- **D1, no self-reference:** the block holds **references only, no hashes.** Hashes are measured by `bind` after assembly and stored in a separate binding output. The pack cut ends before `## Return pointer`, so a later pointer write cannot change it.
- **D2:** the block sits in a fence under a `## Task agreement` heading placed before `## Return pointer`. **Headings inside fences are not targets.**
- **D3:** the binding stores the raw cut bytes (base64) as a historical snapshot, plus the record sha, the cut sha and the counts.
- **D4, book instance:** the lab uses the sha256 of the resolved absolute book root. A binding compared against another root is refused as `instance-mismatch`.
- **D5, the legacy profile:** an explicit data file of exact headings. **Its match to the core's current recognized format is unconfirmed;** the core code was not read. That is a builder item.

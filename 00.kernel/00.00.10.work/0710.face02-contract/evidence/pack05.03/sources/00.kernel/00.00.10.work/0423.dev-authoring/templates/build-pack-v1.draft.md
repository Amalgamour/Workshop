# Pack template - development authoring v1 (draft)
Compute fills [C]; intelligence fills [I]. This is a readable contract, not an implementation schema.

[C] Source/work/pass/template identity; draft stamp; provenance and source links
[I] Goal
[I] Scope: included / excluded / allowed writes
[I] Finish criteria; executor/reviewer where not explicitly supplied by source

## Notes and source coverage
[C] Declared note inventory and exact source identity
[I] disposition: integrated (#NN) / deferred (why) / rejected (why) / unresolved

## #NN - [I] Title
[I] Purpose and requested change
[I] Requirements and boundaries
[I] Interfaces and dependency references
[I] Observable acceptance and expected evidence
[I] Note/decision references and open choices
[C] Number, formatting, resolved references/pins and validation feedback

## Dependencies
[C] Declared resolver results: resolved / missing / stale / conditional / ambiguous
[I] Missing relationship or environment details, when required

## Review and handoff
[I] Prime assessment of exact draft and unresolved design issues
[C] Completeness/source/dependency checks; draft and review digests
[C] Frozen source snapshot manifest and emitted work-page path
[C] Correct return intent/status, preservation and scope footer
[I] Any task-specific stop/escalation conditions
[C] Release remains separate; no approval or builder launch inferred

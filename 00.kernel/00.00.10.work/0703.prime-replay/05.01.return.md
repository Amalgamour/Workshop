code, selected paths and code ranges, and supplied all judgment. The audit checked

A clean day exit means the event journal is readable, not that the intended work
succeeded. Both daily views returned 0 while each recorded an unsuccessful review
route. This distinction needs to remain explicit in routine Prime reporting.

## Factfind / Hostile / Overflow / Unprompted

Factfind: every delivered declared artifact matched, yet execution dependencies
were incomplete. Byte fidelity and operational completeness are different checks.

Hostile: a preflight that accepts any attention result can certify a broken boot.
Testing the expected state matters more than testing only an allowed exit code.

Overflow: declare and package dependencies recursively, including dynamically
invoked adapters and their pinned support, without treating all repo files as a
boot kit. Record exactly which outputs an interface gathers by default.

Unprompted: tool quality includes refusing unsafe completion. These refusals helped
keep an incomplete experiment honest. They do not compensate for the failed delivery
or establish a working factory line. The lab found a real gap before it became an
unexplained fresh-Prime failure, which is valuable despite the incomplete comparison.

date: 2026-11-02
who: Codex Prime

Director request: draft the dev cycle and template, then pack for coding. Compute must know the N4NN source, linked N5NN work page/pass, notes/scope and dependencies; receive work #NN at a time, build the document and support review before sending. Models supply meaning, not remembered formatting/paths/hash/schema assembly.

Observed failure of current process: the old pack assembler takes a complete strict JSON request and committed Git blobs, so Prime still authors metadata, numbered items and dependency declarations beforehand. It is a packaging backend, not an incremental authoring interface. The actual operator pilot needed 4 temporary scripts, 8 setup categories and 3 record attempts; compute correctly rejected typed-field and encoding mistakes, but did not prevent manual reconstruction. Source: 0707/05.09.return.md and evidence/lab05.11.

Reuse candidates: accepted pack assembler/checker, dependency declarations/reader and current source snapshot conventions. The assembler is commit-only and refuses working-tree fallback; current work is largely uncommitted, so never pretend it can package observed-file inputs unchanged. New adapter must keep observed bytes and commit blobs distinct. Existing jobs formatter has outdated route/state/stamp behavior; do not copy that policy merely to reuse numbering.

Design goals: source-linked sessions; small per-item semantic input; compute-owned template/address/pass/#NN/UTF-8/source hashes; declared source-note coverage; dependency lookup with missing/conditional states; exact preview/review; edits invalidate mechanical readiness; no automatic release. One authoring record owns the draft; Markdown is derived until publication. Scope is pack authoring, not universal faces/worker dispatch/kernel rebuild.

First implementation should be usable by current Prime through app entry, not just a schema demo requiring another handwritten giant request. New drafts only, preserve existing packs/captures and make refusals actionable. Notes/requirements and Director decisions remain attributed; compute does not classify arbitrary discussion as authorization.

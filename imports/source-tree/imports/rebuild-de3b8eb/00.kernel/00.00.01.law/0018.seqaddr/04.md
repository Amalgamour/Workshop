## Why one name
Why: because a person should not have to see the rank.

Body: The address is internal. The page holds the title. The face does not. Face 04 carries the inherited page title, and that view is never stored. The full name is the scan.

## Coordinate
Why: because a short address is not a broken one.

Body: The coordinate ends at the first token that is not an axis. DD.title is as valid as DD.SS.BB.PPPP.title. A face is a child of the page. It does not wear the title. Dots after the coordinate are not rank.

## Hierarchy
Why: because a later number will be obeyed as the parent if reservation is only a width.

Body: On every axis, 0 through 9 are reserved. 01 and 0001 are the same rank. They are written 01 through 09 because an axis is two digits at minimum. Hierarchy exists in that band unless a page states otherwise. Outside it, peers do not outrank. Proximity is not lineage.

## Envelope
Why: because the scan has to see a retirement without opening the file.

Body: The order is coordinate, title, version, then 09. 09 is the last piece of any tail. Nothing follows it. A desk retires as DD.title.09. A face retires as FF.VVV.09. The seat is FF.md with version 001.

## Seat
Why: because the first turn has to be obvious.

Body: The active face is FF.md with version 001. A draft wears the version and is not the first turn. Ranking it takes a header check. That cost is accepted.

# How to run a 05.NN batch

1. Worker runs `python librarian-check/lcheck.py <kernel>`.
2. Worker opens a new 05.NN from the template. Fills: page, round 1, answers none,
   status open, job, why, before, proposed, overflow, unsure. Makes NO file edits.
3. Worker sets status review. Stops.
4. Director reads. Writes in `:reply` only. Sets status:
   - approved-to-apply  -> write "> apply" in director
   - needs changes      -> status fix, write the changes
5. If fix: worker opens the next 05.NN (round +1, answers = previous).
   Copies director's changes into proposed. Back to step 3.
   Round 3 still not right -> stop, split the job.
6. After "> apply": worker edits files, reruns lcheck, fills `## done`.
   New errors on reworked pages -> undo, report in unsure. Status review.
7. Director checks `git diff` and the done counts. If good:
   director commits, writes hash, sets status approved.
8. Approved 05.NN files are never edited again. Corrections = new 05.NN.

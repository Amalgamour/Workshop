## Design
Why: because a cold boot with no memory will invent the furniture.

Body: This page holds the designs. Read the local page first. If it has no design, go up. The first design is the 00 files. Face 02 holds the format. This face says what each file is for.

## Sentinel `00.md`
Why: because work inside a container that has not proved itself is not valid.

Body: `00.md` is the sentinel of a real container: a desk, a shelf, or a book. There is no shelf sentinel. It is not the shelf axis. The position is `00`. It is the highest position in that container. It holds the permission to exist, where that authority comes from, and how the container controls its space. Name those as sections. Three introductory lines are not the whole sentinel. If it is missing, the environment is not valid. It is the first file that must be ready. Stop. Shelf number `00` does not exist. `DD.00.BB` is the address of the desk books. Law and syntax live there, including a local override. It is not a shelf. It is not the proof. The proof is `address.proof`.

## Run `00.start`
Why: because a sitting with no start will invent the order.

Body: `00.start` is the desk run. It points at Order on this page. It does not write a second route. A book does not get one.

## Why `00.about`
Why: because the walk is not the reason the desk exists.

Body: 00.about is why. It is not the walk. If it and a book disagree, the book wins.

## Training `00.readme`
Why: because a sitting that is unsure will eat the book.

Body: 00.readme finds the page. It does not do the job. Create it on the desk. A book gets one only when that book needs its own training. The named file wins.

## Find `00.REG.md`
Why: because a missing page will be invented from memory.

Body: 00.REG.md is one row per page. A face is not a row. Syntax carries one. Another book does not, unless a page says that book needs it. A missing row means the page is missing.

## Pointer `00.live`
Why: because the second book has to be named, and must not be a step.

Body: `00.live` holds last, when, goal, pages. A book that carries this file is pretending to be the desk.

## Local axioms `00.axioms`
Why: because a book that copies the shelf is writing a second law.

Body: A book writes `00.axioms` only for a local modification. If the file is absent, climb. Write only what is needed. The rule is on syntax page `0001.rules`.

## Retire home `00.retire.09`
Why: because a retired face needs a home only when one exists.

Body: A book writes `00.retire.09` only when a retired face needs a home. If the file is absent, climb. The rule is on syntax page `0001.rules`.

## Order
Why: because a sitting has to know how to use the system, not only which file opens first.

Body: The walk lives on face `01`, section Order. Axioms, then syntax page `0001.rules`, then syntax page `0003.operate`, then syntax page `0002.schema` if a schema is needed. Then syntax page `0012.gravity`, syntax page `0013.triangulate`, and syntax page `0010.about`. Then the law book named by `00.live`. Other doors point here. A door may keep one first-step line. It may not copy the route list.

## Climb
Why: because locate and authority were the same sentence.

Body: Pages `0000.invariant` through `0008.map` state why a page may exist and what shape it takes. The address climb is law page `0018.seqaddr`. This page points. It does not copy it.

# Colab brief

Law 0036 remains the historical behaviour baseline. This template does not use its Ask line.

## Role and mode
Name the mode: open design Colab, hostile read, diagnostic comparison, or controlled experiment. A model label is not a role. Prior involvement is disclosed. A self-test is labelled as a self-test.

## Purpose and question
State the project purpose and the one question this investigation can help decide.

## Built state and known gaps
State what is built and the known gaps. An unknown stays unknown.

## Reasons and assumptions
Give the relevant reasons and assumptions. Do not replace them with a score.

## Scope and sources
Give the exact scope, source cuts, and reading order. A named file is not whole-page coverage. Do not follow HEAD.

## Dependencies
Separate supplied, withheld, and unavailable. Missing access is not invented. A ZIP recipient has no local path merely because a prompt names one.

## Capabilities
State the actual read, write, execute, and network capabilities.

## Method
State the proposed method and the freedom to challenge it.

## Permissions and stop
State the permission boundaries and the stop or escalation points.

## Return
State the return destination and shape. Keep Hostile, Factfind, Overflow, and Unprompted. If scoring is not declared, state the qualitative result.
Do not manufacture a number.

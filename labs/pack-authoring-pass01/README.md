The app door is `app/authoring_tools.py`. Commands and limits are in `PRIME-USE.md` and in `00.kernel/00.00.10.work/0526.dev-authoring/evidence/build05.01/CONTRACT.md`.

This module does not release a pack, file a return, or call the old assembler. Profile `0423-to-0526` is the declared relation. Profile `fixture-authoring` is the isolated test profile. A profile id is not a path. The focused test is `app/tests/test_authoring_entry.py`.

# prime-desk-pass03

Read-only Prime desk overview and work packet. Current work comes from the
assignment record named by `app/development-workspace.json`, read inside the
declared book. A legacy selector is a hint. Standard library only.

Source, return, and review are separate identities. An N5NN review stays on the
source page. Its N1NN path is the return line, with a `.return.md` tail. An N7NN
pack stays on its own page. The band is the page's second digit.

The contract is `00.kernel/00.00.10.work/0524.prime-desk/evidence/build05.03/CONTRACT.md`.
`examples/shape.json` is a shape, not a live request.

```text
python -B labs/prime-desk-pass03/prime_desk.py view --request ABS [--json]
python -B labs/prime-desk-pass03/prime_desk.py packet --request ABS --work-id ID [--json]
python -B labs/prime-desk-pass03/request_index.py --list ABS --out ABS [--accept REL]
python -B -m unittest -v labs/prime-desk-pass03/tests/test_prime_desk.py
python -B labs/prime-desk-pass03/demo.py --out ABS
```

Run these from the repository root with `PYTHONDONTWRITEBYTECODE=1`.

Pass01 and pass02 are unchanged. This lab does not seat `00.live`, call Git, or
import the review-loop successors.

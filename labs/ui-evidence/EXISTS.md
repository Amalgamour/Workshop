## Face and event formats

- A compute .book file is an append-only JSON Lines file for one book. It has a header, then entries with operation, address, time, writer and operation data. [Book format 58–101](https://github.com/Amalgamour/Workshop/blob/5201b24353bf69b901a912d5283a31015560607d/docs/spec/format.md#L58-L101) · [Lane contract 5–8](https://github.com/Amalgamour/Workshop/blob/5201b24353bf69b901a912d5283a31015560607d/docs/CONTRACT.md#L5-L8)
- A .seq file is a plain-text export of one page. Registry, face sections and counter blocks are based on the book. Import checks can report findings before any approved write. [Seq page spec 9–16](https://github.com/Amalgamour/Workshop/blob/5201b24353bf69b901a912d5283a31015560607d/docs/spec/seqpage.md#L9-L16) · [Seq page spec 64–83](https://github.com/Amalgamour/Workshop/blob/5201b24353bf69b901a912d5283a31015560607d/docs/spec/seqpage.md#L64-L83) · [Seq page spec 98–121](https://github.com/Amalgamour/Workshop/blob/5201b24353bf69b901a912d5283a31015560607d/docs/spec/seqpage.md#L98-L121) · [Compute HTTP 164–184](https://github.com/Amalgamour/Workshop/blob/5201b24353bf69b901a912d5283a31015560607d/crates/compute/src/lib.rs#L164-L184)
- wf uses pages/ADDRESS/log.jsonl and published copies under .workshop/logs/. Each entry holds its sequence, actor, kind, event data and the previous line hash. Markdown faces are generated views.

## GitHub Projects

- A field supplies the columns. Status is one available field.
- The same board can be narrowed with a field slice or split into horizontal groups. [GitHub Projects board layout](https://docs.github.com/en/issues/planning-and-tracking-with-projects/customizing-views-in-your-project/customizing-the-board-layout)
- **Fit.** Use the recorded step to place cards. Let a reader narrow the view to one book or one page. ## Linear

- Status columns follow the order of the workflow.
- Collapsible rows add a second grouping, such as team or assignee. [Linear board layout](https://linear.app/docs/board-layout)
- **Fit.** A desk view could group the same cards by confirmed holder when the page log supplies one. [Brief 72–80](https://github.com/Amalgamour/Workshop/blob/5201b24353bf69b901a912d5283a31015560607d/docs/plan/WORK-PAGE-2026-11-25-EOW.md#L72-L80) · [wf page state 38–46](https://github.com/Amalgamour/Workshop/blob/d7da9e8004f7a40e1412f526d82c301e4e15c3f4/src/page.rs#L38-L46) · [wf page state 564–575](https://github.com/Amalgamour/Workshop/blob/d7da9e8004f7a40e1412f526d82c301e4e15c3f4/src/page.rs#L564-L575)

## Trello

- A board can use the same named field on each card, with a different value on each card.
- A field can appear on the front or be shown only in the card detail. [Trello custom fields](https://support.atlassian.com/trello/docs/using-custom-fields/)
- **Fit.** Keep address, holder, step, next, why and ruling visible in short form. Open the card for the supporting record.

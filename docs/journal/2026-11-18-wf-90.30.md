## Lessons

1. **Pack Start must be the current wf-next.** Fast-forward first, then pack. Entry 16 and the later restore (a00bc53) both came from this miss.
2. **A template change reprints the past, unless the pack stores the version it used.** That is axiom 6. Tester caught it on 05.02 because a test on real pages was missing. That test now exists (tests/wf.rs:1388).
3. **A short list of bad characters will miss the next one.** A category table covers the kind. Typed flags are not enough: builder text arrives later, on a different path.
4. **Lowest-trust text is escaped on output, not deleted.** The log keeps the evidence. The screen stays honest. (t309u-t312u)
5. **A merge of a branch that deleted a past file will drop that file,** even when you mean to merge so the file is kept. Restore it after, as a00bc53 did.

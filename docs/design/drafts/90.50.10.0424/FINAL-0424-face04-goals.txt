wf board with holder, step and next

What this page is: each line of the book-level board (`wf board` with no page) shows that page's holder, current step, and next step. It reuses the data the page board already shows at src/board.rs:272: the claim field, the pass tail, and pass_next.

What it does not do: it does not change column names. WF-BOARD Q1 (column names) stays open for Matthew. Prima's default, already in src/board.rs, is used: tool words are the columns, body-shop words are side labels only. It does not add a session lockout holder (that is 0423). It does not edit src/lib.rs. Help text stays as it is.

How the three fields are chosen:
- The current pass is the highest-numbered pass whose tail is not "closed", the same rule status already uses.
- Holder is that pass's claim, or the word none when the claim is empty or there is no such pass. This is the same field short_card prints at src/board.rs:272. After a return, the claim may still name the builder; do not invent a new "between steps, nobody holds it" rule here.
- Step is that pass's tail (the same word the page board prints at src/board.rs:271), or the word none when there is no such pass.
- Next is pass_next for that pass. When there is no such pass, next is "Prime writes a 06 note, then wf draft <page>". If the page is halted, next is the halt sentence already used by status (how_to_resume is already imported into board.rs). Copy those two sentences into board.rs; do not edit status.rs.

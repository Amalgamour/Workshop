# Director words, t381u (2026-11-19, 11:20 AM EST)

Question asked (t380s1435): "When a rule file changes under an open pass, what should happen?"
Options offered: "Lock the pass (strict)" / "Raise it to Prime to close or redraft".

Matthew's answer, verbatim:

> It never changes mid pass only after review and before a new draft starts

## What this means in plain words
- A rule file (a linked kit doc the AGENTS.md points to) must not change while a pass is open.
- The only time it may change is in the gap after a pass is reviewed and before the next draft starts.
- So a change found under an open pass is out of rule: the tool treats the pass as locked (strict), not something to quietly accept.

# Lessons

This folder is the Workshop's lesson book. It is the primary source researchers use (t507u, 23 Nov 2026).

Start at [INDEX.md](INDEX.md). Scan that menu first. Open only the lessons that match your task, so you spend less usage.

When you add a lesson, add a row to INDEX.md.

## The rule (t506u, 23 Nov 2026)

Every lab ends with a final learning report by its builder. The other builder cross-checks that report. The lessons are kept in this folder.

After that cross-check, the lab's LESSONS.md is copied in here.

## One lesson looks like this

- Title
- What happened
- Why
- What to do next time
- Source cite: a commit, a file:line, or a check

Keep the words short and plain.

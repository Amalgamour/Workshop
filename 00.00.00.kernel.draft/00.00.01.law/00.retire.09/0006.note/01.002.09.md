## Job
This page is for the model.
A note is how the system remembers the work. Memory does not keep it.
A note lives on the page it is about. This page says how. It does not collect the notes.
An insight about another page lands on that page, face 06. Not on the page being typed.
A sitting that does not note the work loses it. That loss is silent.

## Draft
A note tied to a draft lives on that draft. Face 06 alone is the hole.
A strike is a line through. It stays until that face draft is done.
When the face is approved, the struck notes are cleared. An unstruck note is not done.

patch: 2026-10-08. A note, a patch, or a strike may live on an active face. They keep it from going stale. They merge when the next draft is written. The new face is clean because the marks were absorbed. A draft that leaves them behind is the stale cut.

## Not
A note is not a task and not a ticket. Those are page 0005.
A note does not change the king. It does not edit a locked face.
Silent work is a halt. Overflow lands on the page it is about.

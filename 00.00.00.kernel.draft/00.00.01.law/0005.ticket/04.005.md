## Task

source: [01 / Task](01.005.md#task); [02 / Task](02.005.md#task)

why: Local placement preserves what the work is about.

Face 05 holds work about its page. Internal tasks use 05.01 through 05.49 and name a target plus an instruction. The id is the file name. An open task is `05.NN.md`. A closed task is `05.NN.closed.md`. A task names a completion condition. A task that has its id, its target, and its instruction, and lacks that condition, is not complete. The condition does not mint permission. This teaching page describes that work; it is not a work queue for the whole book.

The compact form selects the useful handle: Task: id 05.01-05.49; local target; instruction; completion condition. Open file 05.NN.md. Closed file 05.NN.closed.md. Closed stays. The number is not reused. Missing condition -> not complete. The condition mints no permission.

## Ticket

source: [01 / Ticket](01.005.md#ticket); [02 / Ticket](02.005.md#ticket)

why: Outward work needs an explicit journey and return.

Outward tickets use 05.50 through 05.99 and require a path, an instruction, and a return destination. The id is the file name. An open ticket is `05.NN.md`. A closed ticket is `05.NN.closed.md`. A ticket names a completion condition. A ticket that has its path, its instruction, and its return, and lacks that condition, is not complete. The condition does not mint permission. A ticket missing its path is invalid; a path without an instruction is not ready. Task and ticket ranges remain separate.

## Sweep
One book. One page. Then the next. Book `00` first. Book `01` after. Do not open both in one job.

A page is a folder. A face is a file. `#NN` is one page, or one face if the page is thick. Do not batch the book.

## Check
1. Notes and tickets first. Strike what is already on a face. What is still true lands on the draft. A note is not a face.
2. Read the faces. If they do not agree, note it on the draft. Do not fill the hole from memory. A cite is an intent key. A page with none is a hole. A date is not proof.
3. Write the drafts. Version plus one. Do not edit the live face.
4. Align the drafts against each other. `01` is the rule. `02` is the card. `03` is the menu. `04` is the person read. The shape can be uncovered from any of them.
5. Check face `08`. If the page needs another page to work, the map names it. If it needs nothing, say so.
6. Sign the drafts. A signature is not a promote. Director review is required before the signature.

More than one page only if the director asks. Gravity is five jobs. If the emit would pass that, stop before the next page. A cold model must be able to find the page from the door, the readme, or the book sentinel. The walk is one sentence. It lives on page `0014`. Any other full route is a hole. Furniture is checked with the book. An unlabeled old door is retired. A note that contradicts the header is a hole, not history.

## Hold
Do not edit a live face in place. Draft the face, version plus one. How a version is stamped is the page titled `write`. Notes live on the draft. Tickets stay out of live. A sweep is not a promote. A promote is one move. Check the cite before the lock. A locked page does not carry `9`. Check the state. A lock means state live. A lock that still says draft is a fail. The sweep missed this. It checked the cite and not the state. `9` means do not trust it as it stands. Use it only when the page is known unfinished. Do not put it on a draft because another page is unfinished. The old faces retire off the page. Then lock. Then the page is clean. Do not split that into three asks.

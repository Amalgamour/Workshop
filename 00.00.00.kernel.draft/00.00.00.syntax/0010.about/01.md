## How to read a page
A page is a folder, `PPPP.title`. That short name is the compact form. The full form is law page `0018.seqaddr`. This page points. It does not copy the grammar.
The page holds the title. The face does not. The stamp carries `keyword:`. The folder is still the title.
Faces are `01` through `08`. `09` is the end of the tail, not a face. `00` is the highest position in a desk, a shelf, or a book. The file is `00.md`. It holds the permission to exist, where that authority comes from, and how the container controls its space. The file `00.md` is the sentinel of a real container. There is no shelf sentinel. It is not the shelf axis. Shelf number `00` does not exist. `DD.00.BB` is the address of the desk books. Law and syntax live there, including a local override. If `00` is missing, the environment is not valid. It is the first file that must be ready. It is not the proof. The proof is `address.proof`. The design of that file is syntax page `0014.design`.
Face `01` binds. Face `02` is the card. Face `03` is the menu. Face `04` is the person read. Face `06` is a note. A note does not govern.
If two faces disagree, bring both to the authority. Do not delete either. The home of that rule is law page `0001.law`.
A one-digit mark is an axiom. It is not an axis. An axis is two digits at minimum.

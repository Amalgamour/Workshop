## Job
This page names two kinds of work. It does not hold the work.
They stay in separate lists. Either list may be empty.

## Task
A task is internal. It points at a page in this book.
A temp page is a valid target. It does not need an outward map.
The instruction says what to do. A task with no instruction is not a task.
The list lives on face 05 of the page the work is about.
A task uses 05.01 through 05.49.
When the work is done, the number is deleted. The lowest open number in that range is reused.

## Ticket
A ticket points outward. It is not a ticket until it has a path.
A name with no path is invalid. That does not make a task invalid.
The instruction says what the outward work is, and where the return comes back.
A ticket with a path and no instruction is not ready. It waits.
A ticket uses 05.50 through 05.99.
When the work is done, the number is deleted. The lowest open number in that range is reused.
The two lists do not mix. An invalid ticket does not empty the task list.

## Number
The number is not a test. A test key is a different thing, and it does not promote.
A task number and a ticket number do not share a range.

## Not
Notes are page 0006. A note is not a task and not a ticket.
Work that touches the king may read page 0001 and cite it. It may not copy the lines, edit, lock, or add a line.
If the law door is off, the work refuses. It does not repair the door.

# drafting

# design

    1. copy the existing work and add a .draft tail
    2. Add notes from memory to the face you are working on. 
    3. Was a check done for additional sources?  If no do it add notes
    4. Add the notes one at a time, striking them as they are merged
    5. Record overflow and unpromptd as notes.  Once all notes are merged next step.
    6. Read the follow face and write notes again - required because a full complete view is needed to write better.
    7. merge and strike notes. 
    8. Read again if no more notes hand back for review. 

# why

- A model must never rewrite a face from memory.  It drops what it did not remember.  Every change starts from a copy and arrives one note at a time.
- A new face has nothing to copy.  It starts as an empty draft and still goes through notes and merges.

# enforcement by the compute (proposed)

- copy: the compute copies the seated face to FF.draft.  The writer sends no body.
- note: add one note to the draft.
- merge: apply one change, citing its note.  The note is struck.
- promote: after review the draft replaces the seated face.
- A full body write is only allowed to create a new face, never to replace one.
- Review checks every note is struck before promote.

# exceptions

- Meters on brand cards are written only by the compute.
- Derived content (boards, contents, menus, paths) is calculated, never drafted.
- A new brand card is drafted by the compute.  The user confirming the meaning is its review.
